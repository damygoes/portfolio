# 🧑‍💻 Personal Portfolio – Damilola Bada

A clean, modern, and fully responsive developer portfolio built with **Next.js 15**, **TypeScript**, **TailwindCSS**, **ShadCN UI**, and **Framer Motion**.

It highlights personal projects, work experience, skills, and contact information — all designed to provide a fast, elegant way to showcase technical ability and personality.
